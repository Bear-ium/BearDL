# Decisions

- **eframe glow, not wgpu.** eframe 0.37 defaults to wgpu. glow is several MB smaller and gives mpv's OpenGL render API a GL context.
- **No `default_fonts`.** Bundled egui fonts add ~1 MB. The app loads the platform UI font at startup (Segoe UI and Segoe UI Symbol on Windows, SF/Helvetica on macOS, DejaVu/Noto/Liberation on Linux). The optional `bundled-fonts` feature restores egui's fonts for systems without any of them.
- **No accesskit.** It saves size, but costs screen-reader support. This can be revisited.
- **Release `opt-level = "s"`.** Baseline window: z = 3.96 MB, s = 3.36 MB, 3 = 3.90 MB. "s" is smallest here. This is re-measured in M9.
- **System curl and tar instead of an HTTP/TLS crate.** Windows 10 1803+, macOS and nearly all Linux distros ship both. On Windows they are called from `%SystemRoot%\System32` so Git's copies don't shadow them. This saves ~2 MB of TLS stack. Downloads are verified with SHA-256 (`sha2`).
- **libmpv via hand-written FFI and `libloading`.** `libmpv2`/`libmpv-sys` link at build time, so the exe would not start without the DLL.
- **Tray.** Windows uses a hand-rolled `Shell_NotifyIconW` (windows-sys is already in the tree via winit), which also provides balloon notifications. macOS and Linux use `tray-icon`, with the `ksni` backend on Linux so GTK is not needed. Notifications on Linux and macOS go through `notify-send` and `osascript`, not notify-rust and its zbus stack.
- **Global rate limit.** yt-dlp only limits per process, so each process gets `global / concurrency`. The approximation is documented in the UI.
- **Title filters are comma-separated keywords** (case-insensitive substring match), not regex. This avoids the regex crate.
- **Cold start is measured from launch to the second painted frame**, using wall-clock timestamps written by `BEARDL_STARTUP_LOG`. Process teardown is excluded: the GL driver takes ~700 ms to unload. About 200 ms of the 233 ms baseline is window and GL context creation, which egui cannot avoid.
- **Idle memory is ~70 MiB private at baseline.** Nearly all of it is the OpenGL driver (NVIDIA). The app's own heap is a few MiB.
- **M0 review folded into M1's.** The M0 diff is a 100-line scaffold, so its review runs together with M1's.
- **yt-dlp uses the PyInstaller "onedir" zip builds** (`yt-dlp_win.zip`, `yt-dlp_macos.zip`, `yt-dlp_linux.zip`). Every yt-dlp run is a new process, and the single-file builds unpack about 25 MB to a temp folder on each launch. If an archive can't be extracted (Linux with no bsdtar, unzip or python3), the single-file asset is installed instead.
- **Updates resolve the release tag once** and fetch checksums and asset from `releases/download/<tag>/`. Nightly and master publish often, so separate `latest` lookups could mix releases.
- **Rollback pins the build.** The checksum of the build rolled back from is stored as `rejected_sha`, and auto-update skips it until a newer release appears.
- **ffmpeg comes from PATH when present.** It is downloaded only when missing, on first run or with the button, and is never auto-updated (about 140 MB). A newer build is shown when the managed copy is out of date.
- **M1 review follow-ups.** The fixes in this commit cover: shutdown hang, curl stall timeouts, rollback pinning, single-tag resolution, safe rotate, path fields applying on blur, channel-change check, first-run ffmpeg, onefile fallback, atomic state file, and the messages. Deferred:
  - Unused deps are scheduled: `serde_json` and tokio `io-util` arrive in M2, the windows-sys features in M7.
  - The extra HEAD request per tool download is kept for progress totals, since it happens only on tool updates.
  - Skipping auto-install while downloads run lands in M2 with the queue.
- **M1 cold start.** In-process time to the second frame is unchanged from M0 (~240 ms). The external figure varies by ±50 ms with process loading and Defender scanning of the larger exe.
- **yt-dlp runs with `--ignore-errors`.** A subtitle 429 or a failed thumbnail must not lose the video. A run counts as successful when yt-dlp prints the final path (`after_move`). Exit 0 without a file means Skipped (filtered out or already archived).
- **The default subtitle languages are `en,en-US,en-GB`, not `en.*`.** On YouTube, `en.*` also matches dozens of auto-translated tracks and triggers HTTP 429.
- **Custom arguments are validated by yt-dlp itself.** The run uses `--simulate` and a URL that cannot be fetched; a usage error (exit 2, `error:` on stderr) means invalid. `--version` as a terminator was tried and does not work: yt-dlp accepted unknown options before it.
- **The reserved-option check** covers what yt-dlp's optparse would accept: unique prefixes of long options, short-flag clusters, a bare `--`, and stray URLs. `--exec` stays allowed, because presets are the user's own. Imported presets are shown before use (M4).
- **Process trees.** On Windows each yt-dlp runs inside a Job Object with kill-on-close, so pause, cancel, app exit and even a crash also kill the ffmpeg it started. On Unix each runs in its own process group, which gets SIGKILL. This replaced the blocking `taskkill /T`.
- **The global rate limit** is split among the downloads running when each one starts. yt-dlp cannot change a running process's limit, so the split is approximate when the count changes mid-download.
- **Queue reorder** writes one row, at the midpoint between its new neighbours. It renumbers only when positions converge.
- **Quick Download of a playlist or channel** expands it into one item per video. A channel root opens its Videos tab.
- **Without ffmpeg**, downloads fall back to the best single-file format, and conversion, merging and embedding are skipped, with a one-time notice. The queue waits while an ffmpeg install is in progress.
- **Thumbnails are not embedded into WAV or WebM**, which do not support it.
- **M2 review items not changed:**
  - The analysis spinner animates while yt-dlp runs. It only lasts a few seconds.
  - Downloads without a known total show bytes instead of an animated bar, so a live stream doesn't repaint continuously.
- **M2 is measured before its review fixes.** M3 re-measures.
