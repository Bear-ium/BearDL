A small, fast desktop app for yt-dlp

Download video and audio from any site yt-dlp supports, keep a searchable library of everything you saved, and play it back without leaving the app. It is native, about 6 MB, and uses no CPU while idle.

Opening it the first time

BearDL is not signed with a paid developer certificate yet, so Windows and macOS warn you before the first launch. The steps below are needed once.

Windows
  1. Extract the zip and open beardl.exe.
  2. If Windows SmartScreen says “Windows protected your PC”, select More info.
  3. Select Run anyway.

On Windows on Arm, the x86_64 build runs under Windows’ own emulation.

macOS
  1. Open the download to extract it. You get a beardl folder.
  2. In Finder, right-click (or Control-click) beardl inside it and choose Open.
  3. In the dialogue that follows, choose Open again.

On macOS 15 and later that dialogue has no Open button. Try to open BearDL once, then go to System Settings, Privacy & Security, and select Open Anyway. Or remove the quarantine flag in Terminal:

xattr -d com.apple.quarantine beardl/beardl
Linux 
tar -xzf beardl-linux-x86_64.tar.gz
./beardl/beardl

The build comes from a recent Ubuntu, so it needs a similarly recent glibc. On an older distribution, build it from source. You also need curl and tar with xz support. For a tray icon, use a desktop with StatusNotifierItem support, such as KDE, or GNOME with the AppIndicator extension.

Checking your download

Each release lists the SHA-256 of every file in SHA256SUMS. Download it into the same folder as your download, then run:

Windows (PowerShell)
Get-FileHash beardl-windows-x86_64.zip
Select-String beardl-windows-x86_64.zip SHA256SUMS
The two hashes should match. PowerShell prints its hash in capitals.
macOS
shasum -a 256 -c SHA256SUMS --ignore-missing
Linux
sha256sum -c SHA256SUMS --ignore-missing

On macOS and Linux, a good file is reported as OK.

What BearDL fetches by itself

The download contains only BearDL. On first run it downloads yt-dlp, and ffmpeg if your system has none, into its own data folder. Both are checked against their published checksums, and yt-dlp is kept up to date.

The built-in player needs libmpv. Without it, files open in your usual player.

  • Windows: select Download libmpv on the Player page. It takes one click.
  • macOS: install it with Homebrew: brew install mpv
  • Linux: install your distribution’s package, for example sudo apt install libmpv2 or sudo dnf install mpv-libs
